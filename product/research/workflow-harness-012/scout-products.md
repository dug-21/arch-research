## Warm/cold record, reuse, and gaps

- Warm read used opencode-001 baseline and its scoped headless credential, the theme watchlist's ruvnet and Temporal entries, and the owner-named memory peers. Unimatrix semantic read returned MetaHarness known nodes #316/#319, Temporal #206, AgentCore Policy/Gateway #202, Claude Agent context lineage #395. The latter findings remain current inputs, and the AgentCore Memory namespace result pertains to memory IAM rather than the already known gateway.
- Cold search used "agent memory platform project scopes audit export" and "Bedrock AgentCore custom namespaces policies memory November 2026." It surfaced AgentCore flexible namespaces and AWS's separate multi-layer write-validation reference design. The April design article was reviewed and updated in September, and the August dated feature release plus current IAM docs control the freshness claim. AWS's reference design attests neither OpenCode custody nor end-to-end immutability. [AWS namespace design article](https://aws.amazon.com/blogs/machine-learning/organizing-agents-memory-at-scale-namespace-design-patterns-in-agentcore-memory/)
- Compared five named external families, the two Unimatrix baselines, plus AWS, Temporal and OpenRouter. Focused retrieval excluded independent benchmark reruns, commercial procurement conversations, complete SDK enumeration, enterprise support-only controls, and contractual data-processing claims. No unsupported silence was coded as product absence.
- Highest-value evidence gaps for triage are child credential custody at real harness boundaries, independent audit anchoring with write completeness, intentional cross-project publish with retraction/lineage, and portable recovery across candidate backends. A second gap is reliable mapping of session-derived learning to the specific agent and definition revisions that caused an outcome. Price pages are dated snapshots by retrieval and only supporting context. Release quotes and performance claims were paraphrased and comparative benefits were not tested.
