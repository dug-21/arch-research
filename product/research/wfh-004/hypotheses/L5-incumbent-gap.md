# L5 — Incumbent-gap

**Run:** `wfh-004` · Issue #48 · phase `hypothesize` · lens L5 · read-only, zero experiments, zero writes.
**Primary source:** `W0-b-incumbent-baseline.md` (inspection-only; §11 ambiguity inherited by every row below). Also W0-a, W0-c, W0-d, SCOPE §3.2/§3.3/§4/§11.

**How to read the delta column.** `STRUCTURAL` = the incumbent's *representation* cannot express it, mechanical reason given. `CONFIGURABLE` = free today behind an unflipped switch — **not a build candidate; it is configuration backlog** (§3). `AMBIGUOUS(A-nn)` = turns on a distinction inspection cannot settle; per SCOPE §11 triage must route these `needs-a-probe`, never `out`. New ambiguities are numbered **A-13…A-19** (§5), extending W0-b's register.

**The organizing observation of this lens, stated once so 36 rows don't repeat it:** the incumbent's addressable units are *session, turn, tool call, subagent-spawn* — and its only matchable predicate is *the tool call* (name + input pattern). Nearly every STRUCTURAL row below is one of four consequences: (i) **no durable unit exists between "session" and "tool call"** — no run, no phase, no step, no obligation, no batch-remainder; (ii) **no authority metadata exists on tokens or calls** — no data/instruction distinction in the stream, no principal on an MCP call or subprocess; (iii) **spend, elapsed time, and phase are not matchable predicates**; (iv) **no principal exists in this environment that the agent cannot write as** (pending A-6/A-11). W0-d §4's sharpest finding — "nothing observes the run as an object" — is (i) restated.

## 2. The drop-list — ambitions already solved; argue for dropping

Every one of these is money saved. Wanting them built is wanting something that exists.

1. **Retrospective resolved-context capture.** Fully commoditized — W0-a says it plainly: *wanting it is wanting LangSmith*. The incumbent's JSONL transcript already holds the raw record. Drop; keep only the *prospective/exclusion* delta (L5-07).
2. **Raw cost measurement.** Solved in-house: `opcost` is an (A) row, and P-16's 61× bug was found and fixed *by building it*. Drop measurement; the open items are attribution (A-10) and enforcement (A-1) only.
3. **Per-call trace waterfall with verbatim I/O.** Family-D commodity. Drop.
4. **Semantic context injection at spawn/prompt/compaction.** Already *running* — three live injection points; W0-b calls Context "the strongest configured concern," the garage ahead of its own baseline. Drop building; the residual is the ledger (L5-07).
5. **Named specialist units, isolated context windows, spawn events, nested-spawn prevention.** Free (rows 1, 3, 5). Drop.
6. **Per-tool-call approval gating.** The field's universal common denominator and the incumbent's core permission system. Drop.
7. **The durable-execution primitive itself.** Temporal et al. are mature; W0-a's honest counter: the primitive does not need inventing, only connecting to agents. Never build the engine; at most adopt one (a triage/HOW question, not ours).
8. **Session-level resume/fork.** Shipped. What's missing is the *run* and *subagent* layers (L5-01, L5-28), not the session layer.
9. **OS sandbox, egress allowlist, credential shielding.** Shipped surface (rows 16–18) — configuration pending A-11, not construction.
10. **Rollback of CLI-mediated edits.** Checkpointing + git. The residual is only the Bash/subagent exclusion (L5-33), and git probably covers even that.
11. **A blocking human gate as such.** Exists. The deficiency is *conditionality* (L5-36), not the gate.
12. **Telemetry pipeline construction.** OTel GenAI + the CLI's exporter are shipped; enabling is backlog, building is waste (pending A-10).

## 4. Residual after full configuration — the headline

Assume every switch above is flipped, every probe A-1…A-12 lands *favorably*, managed settings installed, sandbox on, telemetry on. What survives is large in row-count but **narrow in kind — five absences, four of them representational:**

1. **No durable unit between "session" and "tool call."** The run, the phase, the step, the obligation, the batch-remainder, the "done" state — none exists as an object anything non-model can reference. Consequences: no run-altitude alarms (L5-16), no declared-vs-actual reconciliation (L5-03/27), no cost prediction (L5-23), no durable queue (L5-32), no run continuity (L5-08). This is W0-d §4 given its mechanical cause. *Everything on this list is one gap wearing seven hats.*
2. **No authority metadata on tokens or calls.** Inbound: no privilege field on a span — C-1, unfixable by any hook because a hook cannot restore a distinction the representation does not carry (L5-10). Outbound: no principal on an MCP call or subprocess — the tool server and the OS cannot tell curator from scout (L5-12/13).
3. **Predicates the control plane cannot match.** Enforcement matches tool calls only. Spend (A-1-pending), elapsed time, and *phase* are not matchable — and the phase case has a sting: any self-transitioned phase signal originates from the model, so phase-conditional enforcement bottoms out in self-attestation, C-4's shape recursing (L5-02, L5-36).
4. **No principal the agent cannot write as — in this environment.** The managed tier may provide one (A-6), but the devcontainer today provides the opposite; and C-5 is the untested hole under all CLI-side scoping.
5. **No comparison substrate.** C-3: sampling nondeterminism plus a self-mutating retrieval corpus means A/B is not expressible inside the harness at all — the one residual no probe can dissolve, only an external substrate can (L5-25).

Plus one steering-specific corollary of the representation: **working state is an append-only token stream**, so correction can be appended but a wrong premise cannot be excised (L5-35).

**The honest converse, stated with equal force:** everything else this garage has wanted — role restriction, write firewall, sandbox, telemetry, attribution, bounds, tamper-evidence, even syntactic firewall enforcement — is *configuration of the incumbent, pending probes*. If the probes land, the case for building a harness rests **entirely** on the five absences above, and any proposed build that does not target one of them is re-buying something free. That is not a small residual — absence 1 alone explains most of W0-d's expensive rows — but it is a *concentrated* one, and concentration is what a WHAT run is for.
