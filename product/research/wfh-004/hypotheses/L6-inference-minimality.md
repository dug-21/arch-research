# L6 — Inference minimality

**Run:** `wfh-004` · Issue #48 · phase `hypothesize` · lens L6 (added mid-run by owner steer — SCOPE Amendment A-3) · read-only, zero graph writes.

**Method note.** Every harness function examined was placed in exactly one bucket: **(D)** decidable by computation over structured data; **(I)** genuinely requires a model call, with the argument why; **(P)** pseudo-irreducible — inferred today only because structured information that existed at some moment was not captured. Per A-3 and the BRIEFING this is characterization, not advocacy: **(I) findings are reported as confidently as (D) ones**, and minimality is scored at triage screen 9, not here.

**The organizing observation, up front.** Reading W0-d against this lens, the garage's pain record is not dominated by hard semantic judgments that went wrong. It is dominated by *arithmetic nobody ran*: a subtraction (P-12), a set difference (P-13), a string-equality check (P-08), a digest comparison (P-20), a state machine (P-03/P-07), a timeout (P-10), a re-emit of a number that already existed in structured form (P-05, P-16). The general principle the reservoir items share: **information that was structured at the moment it was known was discarded, and a model was later asked to re-derive it from prose — usually wrongly or not at all.** The capture-point restatement: *capture at the moment of knowing; compare at the moment of checking; reserve the model for judgments that were never structured to begin with.*

## 5. Abilities that exist only below an inference threshold

- **Replay / reproduction.** A trajectory is replayable iff every nondeterministic leaf is (a) enumerated and (b) recorded. A *legibility* threshold — but count matters because each unrecorded or un-enumerable leaf breaks the property entirely, and diffuse inference is unenumerable by construction. Evidence: W0-b C-3 declares A/B "not expressible"; Temporal buys replay by *forbidding* nondeterminism outside declared activities — the existence proof that the threshold is real and crossable.
- **Controlled comparison (A/B) — and therefore Self-improvement as a concern.** Downstream of replay plus corpus pinning. P-18: sixteen method versions shipped, zero comparisons ever run. **The garage's Self-improvement concern is not blocked by missing ambition; it is blocked by inference density making two runs incomparable.** The strongest cross-concern claim this lens makes: the entire Self-improvement column waits below the threshold.
- **Caching / idempotent skip.** "Same input → same answer" permits skipping completed work on resume and memoizing checks. One inference call inside a step voids the guarantee for that step. Threshold is per-step and binary.
- **Formal argument / guarantee.** A security property is *statable* only over the deterministic path: "no model in the decision path" (L6-14) is what converts "the agent usually complies" into "the call cannot succeed." C-4's category difference is exactly this threshold seen from the security side. Any inference on the enforcement path demotes a guarantee to a tendency.
- **Predictable cost.** Deterministic functions have knowable cost; each open-ended inference point adds a heavy-tailed term. L6-26's intervals tighten monotonically as inference count drops — a *continuous* function of inference density where the others are cliffs.
- **Testability.** A D check gets a unit test with a definite verdict; an I leaf gets an eval with sampled confidence. Below the threshold the harness's own correctness is CI-checkable; above it, harness QA inherits all of LLM-eval's problems. (P-16's parser bug is the caution that D functions still need tests — determinism buys *testability*, not correctness.)
- **The confident-wrong-number class disappears structurally.** FP-3 is generated by a model re-deriving structured facts through prose. Below the threshold (numbers transcluded, never re-stated) the failure class has no channel to occur in — not reduced, removed.
