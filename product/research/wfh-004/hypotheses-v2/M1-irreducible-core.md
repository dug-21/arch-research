**Lens statement.** Every candidate answers one of four questions: **(Q1)** what is the deterministic envelope around a genuinely required model call · **(Q2)** what capture turns a (P) inference into arithmetic · **(Q3)** what gives a retained model output something to be checked against · **(Q4)** what exists only below an inference threshold — *including abilities that protect against the **deterministic** error mode (W0-e §6.5), which this lens is obligated to generate for, not merely concede.*

## 2. The irreducible core — testing W0-e's 4–6 estimate

**Result: the estimate holds at five families (plus the payload).** The M1-01…07 envelope applies to all five identically.

| # | Family | Why irreducible | How small the question gets |
|---|---|---|---|
| **I-1** | **NL → typed object at the human boundary** (steering, intent, scope amendments arriving as prose) | Unbounded natural language authored at arbitrary times; no finite rule-set covers the distribution (C-2's true core). **Pushing the formalism onto the human is §6.7's regression** — the translation must live somewhere, and the model is the cheapest adequate translator | Emit into a fixed schema (F-1: the schema checker supplies the guarantee); harness echoes the typed object back; **the human's confirmation of the echo is the correctness check — the model never needs to be right unilaterally** |
| **I-2** | **The residual semantic categorisation at gates** | After M1-14/17/22 strip existence, equality and arithmetic, a genuinely semantic core remains ("is this artifact's altitude the claim's altitude"). **No independent representation of *meaning* exists to check against, by definition of the residual** | Forced binary or small enumerated set · minimal evidence span · required locator the harness resolves · reasoning emitted separately · N samples with disagreement rate. **A categorisation, never an essay** |
| **I-3** | **Recall-oriented generation** (hypotheses, candidate causes, adversarial cases, test inputs) | §6.6: a deterministic filter with no generator has nothing to filter. The component's best-evidenced use (F-4, loud failure mode). **Removing it removes the recall — including the attacker-model generation both domains' records cannot supply** | No smallness needed — over-generation is the desired bias. The envelope guarantee is a quota plus a deterministic downstream filter |
| **I-4** | **Linguistic equivalence / dedup** | F-5: inherently linguistic; no deterministic total function; error symmetric and human-comparable. Embedding pre-filters shrink the pair set but the ambiguous band is irreducibly semantic | Pairwise binary, **only on the band a deterministic similarity pre-filter cannot settle** |
| **I-5** | **Prose for the human reader** | F-6: the human is the checking layer, in-loop, at read time | None needed — but M1-22 applies when the same prose is *also* machine-consumed |

**Deliberately kept on the model but not core:** planning unfamiliar tasks (F-13) — demoted from "trusted" to "referent-checked" by M1-19; **judgment errors in plans remain irreducible and undetected until execution, honestly.**

**What joins the deterministic guarantee list** — beyond W0-e's seven, six more, all mechanical: **question identity** (M1-03) · **attempt identity in an append-only sequence** (M1-05) · **evidence provenance** (M1-06) · **typed non-answer taxonomy with fail-closed default** (M1-04) · **cost emitted at call time** (M1-08) · **the disagreement rate when N>1** (M1-24).

## 5. Below-threshold abilities

Each exists **iff** its threshold holds; above it the ability is not degraded but **absent**.

1. **Bitwise replay** — iff every model output on the path is consumed via its recorded symbol. One re-sample anywhere and F-19/F-21 make replay a fiction. → M1-27, feeding M1-31.
2. **Memoization** — iff the step is a pure function of addressable inputs. Payoff measured in our record: P-20's re-read tax, 4/4 runs.
3. **A statable guarantee** — iff zero inference on the enforcement path. **Not a spectrum: one inference call demotes the whole path to tendency.** → M1-26.
4. **Meaningful test green** — iff the checked property is total (the check "never has an opinion"). S-05/S-06 show what green means when this fails.
5. **Predictable cost** — iff no open-ended generation loop on the path.
6. **Resolvable A/B attribution** — iff both paths are replayable and pinned. **The garage's entire reflexive-improvement premise sits behind this threshold and is currently above it.**
7. **Idempotent retry** — iff the step is deterministic; for model calls the only honest substitute is at-most-once with record-before-act (M1-07).

**Counter-thesis, priced in:** dropping below the threshold **removes the stochastic-error detectability that repetition provides** (§6.5). M1-28/29/30 are the compensating instruments, and **any triage adopting the below-threshold abilities without them is taking the observability regression silently.**
