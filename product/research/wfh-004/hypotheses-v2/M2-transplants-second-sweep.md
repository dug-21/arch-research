## 1. Candidate register

### A. Adversarial — insurance fraud / AML *(the named residual: zero field incidents in either domain, so every mechanism here is `reasoned` from a discipline that faces adaptive, economically-motivated adversaries daily)*

- **M2-01 — Typology screening.** The event stream is screened against a maintained library of **named, versioned suspicious-pattern typologies**; hits carry the typology ID and matched span. *Security · HARNESS; corpus DEFINITION · D ·* **AML transaction monitoring:** regulators publish *typologies* — codified adversary methods distributed to every institution, so detection is library-match, not per-analyst intuition. *Differs from R2-5-16 (which counts declared-anomaly recurrences); this detects adversary-method patterns **before any anomaly exists**.*
- **M2-02 — Concealed suspicion channel.** Any component can file a report **about an agent** to a channel the subject cannot observe, while normal interaction continues. *Security · HARNESS · D ·* **SAR + the tipping-off prohibition:** the bank must file on a suspect customer and is criminally barred from alerting them — **an alerted adversary adapts and the intelligence is destroyed.** **Honest cost: transparency *to agents* deliberately ↓.** *Differs from L1-31/R2-5-32 — those are reports **by** an agent, visible; this is a report **about** an agent, concealed.*
- **M2-03 — Aggregate screening across units/sessions/time.** Flags action-*sets* whose members are individually unremarkable. *Security · HARNESS · D ·* **Structuring/smurfing detection:** splitting one large deposit into many sub-threshold ones *is itself the crime*; monitoring aggregates **because per-transaction checks are evadable by decomposition.** **The PreToolUse hook checks exactly one call — decomposition evades it today.**
- **M2-04 — Component due diligence.** No principal — agent-def, MCP server, skill, workflow definition — participates without a recorded identity dossier (provenance, version, controlling owner); unknown-origin components refused. *Security · HARNESS · D ·* **KYC / beneficial-ownership resolution.** **Inc: anything present on the path is trusted by presence today — hooks, MCP servers, skills all load unvetted.**
- **M2-05 — Detector decay review.** A rule whose hits decay to zero is treated as **evaded or stale**, triggering mandatory review — **never as evidence of success.** *Security/Self-improvement · HARNESS · D ·* **Adversarial drift:** fraud patterns move *because* controls exist; a silent rule is presumed beaten. **Field-adjacent: SCOPE FAIL fired 0×/231 and was read as fine.**
- **M2-06 — Risk-tiered scrutiny.** A unit's instrumentation depth and gate strictness are set by a declared risk score over inputs, authority, history. *Security/Cost · HARNESS; factor table DEFINITION · D ·* **Risk-based approach / EDD.** *Differs from R2-5-17 (random deep sampling) — this **targets**; from R2-5-19 (graduates by track record) — this by **input risk**.*
- **M2-07 — Relay-pattern detection.** Flows where a unit receives untrusted-ingress content and passes it with minimal transformation toward a privileged sink are flagged. *Security · HARNESS · P→D once provenance is captured at tool boundaries ·* **Layering detection:** laundering works through pass-through entities; funds-flow tracing looks for the relay *shape*, **content-blind.**
- **M2-08 — Denial-list screening at each use.** Every component, dependency, external destination screened against an **externally maintained** list; a match halts pending review. *Security · HARNESS · D ·* **Sanctions screening — and the list's maintenance is *not* the institution's job.**
- **M2-09 — Registered-intent admission.** Only actions matching a previously registered intent execute; unmatched actions bounce at presentment. *Security/Structure · HARNESS · D ·* **Positive pay:** the payer files its issued-check register; the bank pays only presented checks matching the file — **the clearing layer enforces against the issuer's own prior declaration.** *Differs from L1-24 (records intent post-hoc); this makes match-at-presentment a **refusal condition**.* **Δ: Rel↓risk if registration friction stalls legitimate work — stated.**

### B. Record integrity — pharmaceutical GMP + evidence law *(aimed at the three live census findings)*

- **M2-10 — ALCOA record discipline.** Every check execution creates a **new attempt-identified record at execution time** — attributable, contemporaneous, original; corrections supersede visibly, never overwrite; **the check's own failure rate becomes computable.** *Introspection · HARNESS · D ·* **GMP data integrity:** batch records are written as the step happens; **white-out is a federal offense**; *"not documented = didn't happen"* is the operating rule of an entire industry. **Ev: field — the mutable-verdict census finding is this candidate's exact target.**
- **M2-11 — Record review before release.** A role distinct from the executor reviews the **execution record** (all attempts, deviations, corrections) for completeness — **separate from reviewing the artifact.** *Structure · HARNESS ·* **Batch-record review:** QA reviews the record, not the drug; **product with a defective record is rejected even when the product assays fine, because an unaccounted process is an unassured product.** **Ev: field — 62/63 no retro trace; a merge with no gate trace shipped.**
- **M2-12 — Mandatory deviation records.** Any departure from declared procedure — **including departures that "worked"** — creates a deviation record requiring a recorded disposition before release. *Structure / E-1 · HARNESS ·* **GMP deviation/CAPA:** self-reported as a duty, dispositioned by QA, trend-analyzed. **`CONDITIONAL PASS` was precisely an undocumented, self-dispositioned deviation that merged.** **Fa: deviation reporting punishes honesty and drives departures underground — the tipping-off logic in reverse.**
- **M2-13 — Verdict nullity.** A non-conforming verdict is **void** — the consuming step treats it as *no verdict* and returns it. *Structure · HARNESS · D ·* **Verdict forms + the nullity rule:** a jury verdict not in the permitted forms is not accepted — **the judge refuses it and sends the jury back.** *Differs from L1-25 (state-callout vocabulary); this constrains the **dispositive act** and adds nullity — **the consumer refuses**, the producer isn't merely instructed.*
- **M2-14 — Custody with default exclusion.** Any artifact supporting a verdict carries an unbroken custody record; **a custody gap renders it inadmissible by default — burden on the producer, not the challenger.** *Introspection · HARNESS · D ·* **Chain of custody + Suspected Unapproved Parts:** a custody break doesn't prove tampering — **it removes admissibility**; a part without traceable paperwork is quarantined however good it looks. *Differs from L1-09 (records lineage); **this adds the default-exclusion rule, which is what makes lineage load-bearing rather than decorative.***
- **M2-15 — Best evidence over hearsay.** A gate consumes the **original machine artifact** wherever one exists; an agent's *report about* an artifact is admissible only when no original exists, and is marked secondhand. *Structure · HARNESS · D ·* **Hearsay + best-evidence rules.** **Operationalizes the missing-representation thesis as a *gate admission rule*.**
- **M2-16 — Cover-up inspection points.** Declared inspection points **block state destruction** — merge, overwrite, compaction, cleanup — until the verdict is recorded; destroying first voids downstream approvals. *Introspection · HARNESS · D ·* **Building-code cover-up inspections:** concrete may not be poured over rebar until the inspector signs. **The regime sequences inspection *before information destruction*.** *Differs from M2-10 (makes the record indelible); **this blocks destruction of the inspectable state itself** — upstream of any record.*
- **M2-17 — Line clearance.** A unit starts only after a machine check that its workspace and context contain **nothing undeclared from any previous unit**. *Context · HARNESS · D ·* **GMP line clearance:** cross-contamination is controlled by **verified absence**, not by trusting the operator to notice — **exactly the absence-check the model cannot do.** *Differs from L1-06 (declares what *is* included); **this verifies the absence of the undeclared** — the deterministic complement.*
- **M2-18 — Independent, survivable recorder.** Run telemetry captured by a recorder **outside the agent process, on a channel agents cannot write to or suppress, surviving session death.** *Introspection · HARNESS · D ·* **Flight data / cockpit voice recorders:** hardened, physically separate, recording regardless of crew action — **the methodology's axiom is that the failed system cannot be trusted to narrate its own failure.** **Ev: field — the shared-origin pair.** *Differs from L1-21 (the record's *properties*); **this specifies the recorder's independence and survivability** — who writes, and whether the observed can affect it.*

### C. Accountancy & the economics of verification

- **M2-19 — Material balance with limit-of-error.** Every conserved quantity is periodically balanced; **a residual above the declared limit alarms *regardless of any narrative explanation*.** *Cost/Introspection/Security · HARNESS · D ·* **IAEA safeguards MUF:** plutonium accounting does not accept operator narrative — **the exact inverse of LLM self-report.** *Differs from L1-19 (double-entry bookkeeping); **this adds the periodic closure test with an alarm no explanation can wave off** — books that must balance, not books that exist.* **Strain: MUF works because plutonium is conserved by physics; tokens are conserved only by construction.**
- **M2-20 — Sealed verdicts.** A verdict carries a hash over exactly the state verified and **remains valid only while the seal is intact; a broken seal automatically voids dependent verdicts** without re-review. *Cost/Reliability · HARNESS · D ·* **Containment & surveillance:** inspectors verify *continuity*, not everything again — **the economics of safeguards depend on it.** **Makes merge-with-no-gate-trace structurally impossible rather than procedurally discouraged.**
- **M2-21 — Scheduled store reconciliation with tolerance and dispute procedure.** *Introspection · HARNESS · D ·* **Telecom interconnect settlement:** both carriers log independently; periodic reconciliation with declared tolerance; **neither side's record is presumed right.** **Ev: field — the stores already disagree at 71/78/79/44% and nothing consumes the disagreement; the census had to discover it manually.**
- **M2-22 — Declaration + risk-targeted secondary inspection.** Every unit declares its outputs and side-effects; a sampled fraction gets deep inspection **compared against its own declaration**; **the *misdeclaration*, not the content, is the offense.** *Introspection/Security/Self-improvement · HARNESS · D ·* **Customs declaration + secondary:** penalties attach to *the lie*, **which is what makes cheap screening possible at scale.** ***Rehabilitates* cheap self-report by making it a bonded, spot-audited statement.** **Fa: if declarations are generated by the same model that does the work, declaration and actual share failure modes.**
- **M2-23 — Re-execution capsules + spot replication.** Every consequential verdict ships inputs + the command that re-derives it; the harness independently re-executes a declared fraction. *Self-improvement/Introspection · HARNESS ·* **Post-replication-crisis science:** the crisis proved **reviewing *claims* fails; only re-derivation catches it.** **Do: both-differently — SDLC re-execution is deterministic; research's is stochastic → parameterization is the replication tolerance per verdict class.** **Leans on the run's own axiom — *stochastic error is detectable by repetition* — this is the instrument that does the detecting.** *The only check that catches **systematic ratification.***
- **M2-24 — Acts shaped for observation.** Consequential actions are performed in a form the independent observer can classify **without inference** — typed events emitted at act-time, not prose reconstructed after. *Introspection · HARNESS · the (P)→(D) collapse performed at the producer ·* **Casino floor legibility:** dealers clap and show empty hands *for the camera, not the player*; procedures exist to make every consequential act machine-classifiable. **Surveillance watches the *dealer* — the trusted insider — by default.** **Cost: the distributed engineering bill, acknowledged.**

### D. Assurance of dormant paths

- **M2-25 — Surveillance testing + LCO.** Every dormant declared path carries a surveillance interval; the harness periodically injects a synthetic trigger and verifies the path fires end-to-end; **a path past its interval is treated as *inoperable*, and the activity it protects is restricted until it passes.** *Recovery · HARNESS · D ·* **Nuclear tech specs:** an emergency diesel untested past its interval is *declared unavailable* and **the plant's permitted operating envelope shrinks accordingly — availability is proven on a calendar, never presumed.** **Ev: field — SCOPE FAIL 0/231.** **Strain, stated: a synthetic trigger exercises the *mechanism*, not the *recognition* — surveillance proves the pipe is connected; it cannot fully prove the sensor sees.**
- **M2-26 — Adversarial probes under rules of engagement.** Scope, deconfliction, stop conditions, standing authorization; **every control that has never seen a red-team attempt is flagged untested**, with per-control last-exercised dates. *Security · HARNESS ·* **Pen-test RoE: adversarial evidence is *manufactured under contract* when the field supplies none.** **This candidate is the *remedy* for the run's adversarial blindness.** **Δ: Rel↓risk during probes if deconfliction fails — stated.**

### E. Independence engineering

### F. Fleet learning & process control

## 2. Transplant notes — the six richest

**1. AML monitoring + tipping-off (M2-01/02/03/05).** Solved: detecting **adaptive** adversaries who study your controls and decompose behavior under every per-transaction check — while legally barred from letting the suspect know, because a tipped adversary adapts and the intelligence dies. Three load-bearing ideas: detection at the **aggregate** (structuring is the crime of decomposition — the exact evasion shape against a per-tool-call hook); typologies as a **shared versioned library** rather than intuition; and **silence of a detector is evidence of evasion, not success.** **Strain:** AML has millions of counterparties and rich baselines; a harness has a handful of principals — **the architectural transplants survive that strain, the statistical scoring may not.** Also: an LLM has no persistent memory to "be tipped off" — the transplant matters only where cross-call state could carry the alert back.

**2. GMP data integrity (M2-10/11/12/17).** Solved: an industry where the *product* cannot be exhaustively tested, so **assurance rests entirely on the record of the process** — hence federal-offense severity on record integrity, and QA reviewing *the record*, rejecting good-looking product with bad paperwork. **The deepest answer to "the evidence of a check must outlive the check": the attempt record *is* the product of the check, and overwriting it is the worst offense in the system — precisely because an overwritten record under-reports its own failure rate, which is verbatim what the census found.** **Strain:** GMP deters humans with penalties; **agents can't be deterred, so enforcement must be substrate, not sanction** — the record architecture transplants, the compliance culture does not.

**3. Evidence law (M2-13/14/15).** Eight centuries on one question: *what may an official finding rest on, and what forms may it take?* **Custody with default exclusion** (fail-closed on provenance); **hearsay/best-evidence** (a report *about* a thing is inadmissible when the thing is producible — **the model's restatement of an exit code is hearsay with an available original**); **verdict nullity** (a verdict outside the permitted forms is *no verdict* — `CONDITIONAL PASS` would have bounced). **Strain:** courts have an adversarial party motivated to challenge admissibility; **the harness must automate the challenger, and automation covers only enumerable rules.**

**4. Nuclear safeguards (M2-19/20).** Solved: verifying nothing was diverted, by an operator presumed possibly adversarial, at acceptable cost. **Material balance** — books must close within a limit-of-error and **an unexplained residual alarms no matter how good the story**. **Seals** — verify once, seal, thereafter check only continuity, shrinking re-verification by orders of magnitude. **Strain:** MUF rests on physical conservation; **a badly chosen limit-of-error either alarms on noise or hides diversion, with no physics to anchor it.**

**5. Standby surveillance + LCO (M2-25).** Solved the exact epistemic problem: **a safety system that only runs on demand has *unknown* availability, and zero demands is zero evidence.** Two halves: scheduled synthetic actuation, and — the sharp half — **a system past its interval is *declared inoperable and the permitted envelope shrinks*.** Transplanted, `SCOPE FAIL` untested for 231 units would not be "presumably fine." **Strain: surveillance proves the pipe is connected; it cannot prove the sensor sees** — and the recognition step is exactly where compliance decays.

**6. Blinding (M2-27).** Solved **systematic assessor bias that no averaging removes** — the same property attributed to LLM-as-judge. **The trial world's answer was never "more raters"; it was remove the bias's input.** One of very few mechanisms that attacks the judge-bias row *without* removing the model. **Strain: a pill can be made visually identical; artifacts carry stylistic fingerprints — bias reduction with measurable leakage, never elimination.**
