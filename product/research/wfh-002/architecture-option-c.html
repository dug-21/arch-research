Who owns what

The stable part vs the part that changes.

The graph declares

stable · rarely moves
  • The nouns — instruction, actor, step, checkpoint, instrument
  • The wiring — what runs what, what depends on what, what guards what
  • The bodies — every file preserved byte-for-byte
  • The rule names — “this checkpoint tests the floor,” and nothing more

The queen evaluates

churns · where rules live
  • The floor & north-star — is the bar met? (binary)
  • The coverage test — has the search gone dry?
  • Cost & caps — the roll-up, and whether it’s over budget
  • Loops & escalation — repeat, count strikes, pull in a human
  • The firewall verdict — the one rule that guards proven
No queen?

It still works, quieter. Hand the graph to a third-party tool that has no engine, and the named rules simply read as prose that tool’s own agent interprets — exactly where a plain-graph design already lives. So this is that design plus determinism: the same floor when nothing’s driving, testable rules the moment the queen is.
